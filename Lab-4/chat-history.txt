⏺ I finished all four tasks in a fresh clone at lab4/39_endless-runner. A
  headless test run passed on every change. I haven't played it with a real
  window and audio, and I haven't committed or pushed anything.

  - Task 1, collision:
    - Speed now has a top limit: Easy 12, Medium 15, Hard 18.
    - Hits are now checked across the whole distance an obstacle moved during
      the frame, not just where it ends up (in game/obstacle.py).
    - Test: an obstacle moving 60px per frame slipped past the player under the
      old check. The new check catches it.
  - Task 2, game over screen: A dimmed overlay shows "GAME OVER" and the final
    score, and the game waits for a key. This replaces the old console print.
  - Task 3, replay: On the game over screen, press 1/E for Easy, 2/M for Medium
    or 3/H for Hard, or Esc/Q to quit. Space is ignored there, so a held jump
    key can't restart the game by accident. Each level has its own starting
    speed and time between obstacles. The first game starts on Medium.
  - Task 4, sound: New file game/sound.py makes the jump, score and game-over
    sounds in code, so there are no audio files to add. If there's no audio
    device, it stays silent instead of crashing. The jump sound plays only when
    a jump actually happens.
  - Other changes:
    - Each obstacle now gets its new speed before it moves, not after.
    - main.py exits when you choose quit.
    - A .gitignore covers __pycache__/ and .venv/.

  To run it: .venv/bin/python main.py. pygame is installed in .venv.

  For your "before" video, check out the original code with git stash, record
  it, then run git stash pop. The new game/sound.py and .gitignore aren't
  tracked, so they stay in place during the stash. That doesn't affect the old
  version, because nothing in the original code uses them.
